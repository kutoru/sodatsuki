# anki

The app relies on the `sodatsuki-helper` custom Anki addon. The addon is based on [Anki Connect](https://git.sr.ht/~foosoft/anki-connect). Learn how to manually add the addon [here](https://addon-docs.ankiweb.net/addon-folders.html).

# python

```
python -m venv python-env
.\python-env\Scripts\pip.exe install easyocr==1.7.2 openai-whisper==20250625
.\python-env\Scripts\pip.exe install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu121
```
